## Result

partition-restoration note below), **4 ids corrected** — three more announcing-update
MP premiums (rows 1–3, the pattern now at ten instances) and one
**base-debt inheritance** into the future (row 4: the Masquerade Swan
costume is an Ark Guardian / New-Year-2026 pass, fourteen months after

Everything else is documented by wiki releaseDates / event pages
fetched live this pass (incl. the whole EVA collab block — Asuka/
Misato 08-22, Rei 08-29, Mari 09-05, the collab gacha + the three
"Pilot in Summer" passes, the collab's event title "You Can (Not)
Evade"), the Module:NikkeCostume/data obtain table, the wiki Event
list page (which resolved the Jinx Player / Nonsense Red rowspan), or
the RESEARCH.md / ev_dates chains.

Notable resolutions: **Tove Baseball Fan confirmed at 2024-10-03** —
the module's "'Swing into Autumn' login reward" shows it belongs to the
Oct 3 2024 update's login event, not the Nov 2023 ALONE SURVIVOR login
(which BUCKET_06 had used as corroborating evidence for Tove's base
debut); the **2nd anniversary** was the Old Tales event (2024-10-31,
its "2nd Anniversary Pass" + "2nd Anniversary Nikke Selection Box"),
settling c231_01; **Aegis the Diver** identified as the Beauty Full
Shot collab story (no standalone event page — it's absent from the
event list for the same reason); the **Ark Guardian** event (2025-12-30)
carries the 2026 "New Year Pass" that c403_01 belongs to.

**Pattern for later buckets (new this pass):** the wiki **Event list
page** (yearly tables) is a compact cross-check for event start dates
— but its rowspan rows (shared event slots, e.g. Nonsense Red / Jinx
Player) mislead naive "next date" parsing; and named event passes can
belong to events far from a costume's recorded date (c403_01), which
is exactly what the module's obtain strings catch.

**Partition restoration (post-pass):** the ten rows verified in
BUCKET_07 that belong to this bucket's planned set (c314, c501,
c570_99, c976, darkhero, favorite_c072/c100/c142/c210, lastkingdom)
