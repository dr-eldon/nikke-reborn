# NIKKE REBORN — Card Pack Plan

*Status: settled · drafted 2025-10-21 · re-based on the wiki's event archive 2026-11-05 — the banner-history packs 2–10 are replaced by five event-named sets (band 60–70 NIKKE entries, a set cut at *Memories Teller* as required — *Old Tales* and *Memories Teller* carry the line's 25 below-band entries — set 2 extended through *Sea You Again* on theme plus one summer add-on, four wave add-ons into sets 3–6), every other model of a set's window riding in as extras; **Base** is unchanged and built*

**Base** is built and unchanged — its roster is `cards/Base.toml`. Everything below the launch day is re-planned below from the dated model dump.

## How a set is cut

- **Cut-offs:** start dates of wiki events (the `Events` archive at the link in *Sources*). A set is named after that event; the set's marquee NIKKEs are dated on the day — one exception, set 2, which extends on theme.
- **Windows:** set N holds every model dated in (cut-off N−1, cut-off N]. Set 2 opens after the launch day (2022-11-04) — Base carries the launch models. Models dated after the final cut-off (2026-10-29) form the pending tail.
- **NIKKE entries:** sets carry 60–70 NIKKE entries — the band that fixes the cut-offs — with two exceptions. *Thematic:* set 2 extends through *Sea You Again* (both summer-island events, 73 NIKKE entries, 72 in the roster) and carries *Helm: Aquamarine* (c353, 2023-08-10) as a single-model summer add-on. *The Memories Teller requirement:* a set must cut at *Memories Teller* (2025-06-12), which sits at the 157th of the 285 entries to print — out of reach for any four in-band windows (their cut-offs land at the 60–70th, 120–140th, 180–210th and 240–280th entries), and five in-band sets would need 300 entries — so the line runs five sets and the deficit (25 entries) sits in the two sets bracketing the 93-entry Golden Coin Rush→Memories Teller span: *Old Tales* (39) and *Memories Teller* (57), with *Fatal Maid* (59) one below the floor. As of 2026-11-05: 358 NIKKE entries post-launch, 285 to print after set 2's 73.
- **Extras:** every other model dated in a window (story characters, Ghosts, Smol chibis, CN-exclusive NIKKEs, event CGs and event models) rides in as an extra of the set whose window contains its date.
- **Curation:** no boss models — the catalog's 8 post-launch ones (all in set 2's window, its curation note) and the 6 launch ones curated out of Base; the single exception, `mbg004_appearance` (Boss: Modernia Intro, 2022-11-04), prints in Base. No Faceless crowd NPCs (Base: c911/c912/c916–c924; set 6 drops the series' continuation c947–c952), no `*_old` legacy sibling models (Base: Rapi_old c010_01; set 2 drops Shifty_old c907_01 and Mast_old c350_old — Shifty's 2023-06-01 `c907` model is in Base, so `c907_01` is a re-release of a Base NIKKE; Mast's 2022-11-04 `c350` model predates the launch, so `c350_old` is legacy art from the launch window).
- **Waves are never split:** a wave's marquee NIKKEs and its sub-flavors land whole in one set or the tail — the pirate crew on set 2's cut-off day (2023-08-03), the Golden Coin Rush bunny wave (set 3: Mary Medical Rabbit and Soda: Twinkling Bunny on the 2024-05-30 cut, Folkwang Moist Rabbit (c242_01, 2024-06-01) and Alice: Wonderland Bunny (c195, 2024-06-06) as add-ons), the Rapi winter wave (set 5: Ein, Rapi, Zwei, 2024-12-26 to 2025-01-01), the NERV trio (set 5, 2025-02-20/27), the RE trio (set 6, 2025-09-24/10-02), EVE/Raven (set 5: EVE on the 2025-06-12 cut, the 2025-06-19 sub-flavor wave as an add-on), the Kuroko's pair (set 7) — or whole in a set: the Persona/Kuroko's wave and the Guilty/Sin twins (both inside set 7). A wave dated after a cut-off rides in as an add-on rather than split across the boundary: set 2's *Helm: Aquamarine* (c353, 2023-08-10), set 3's *Folkwang Moist Rabbit* (c242_01, 2024-06-01) and *Alice: Wonderland Bunny* (c195, 2024-06-06), set 4's *Cinderella Glass Princess* (c511_01, 2024-11-07), set 5's 2025-06-19 wave, set 6's *Velvet Sensual Rabbit* (c316_01, 2026-02-01).
- **The next set:** the pending tail becomes the next set once it accumulates 60 NIKKE entries; its cut-off is the first event start date that lands its window in the band. It holds 1 NIKKE entry today — *Scarlet: Goddeath* (c472, 2026-11-05); the latest archived event, *MARIA-n* (2026-10-29), is the line's final cut-off.

## Why this line (the design space)

The band (60–70) and the *Memories Teller* requirement fix the line's shape. *Memories Teller* (2025-06-12) sits at the 157th of the 285 NIKKE entries to print (358 post-launch, set 2's 73 already released — *Helm: Aquamarine* (c353) included in set 2's 73). Four in-band windows place their cut-offs at the 60–70th, 120–140th, 180–210th and 240–280th entries, so no four-set line with every window in band can cut at 157; and five in-band sets would need 300 of the 285. The Golden Coin Rush→Memories Teller span (93 entries) cannot host two in-band sets (120–140), so a four-set line carries the whole span in one 96-entry *Memories Teller*, and a five-set line splits the span and carries the deficit in the two sets bracketing it:

| Line (NIKKE entries — every line ends in a 1-model tail) | below-band deficit |
|---|---|
| Golden Coin Rush 66 / **Memories Teller 96** / Fatal Maid 59 / MARIA-n 63 — the four-set line | 59 (−1); Memories Teller 26 over the ceiling |
| Golden Coin Rush 66 / **Old Tales 39** / Memories Teller 57 / Fatal Maid 59 / MARIA-n 63 — settled | 25 — 39 (−21), 57 (−3), 59 (−1) |
| Golden Coin Rush 66 / Footstep 49 / Memories Teller 47 / Fatal Maid 59 / MARIA-n 63 | 25 — 49 (−11), 47 (−13), 59 (−1) |

(Add-ons ride with their marquee event's set: in every *Golden Coin Rush*-headed line the two bunny add-ons ride to the *Golden Coin Rush* set; in the *Perfect Maid* / *Kill the Lord* head lines the whole bunny wave is in-window in the *Phantom Thief* window (which also carries the 2024-05-30 event date), so nothing moves. The *Sin Editor* (2026-01-15) fourth cut is the other in-band option between *Memories Teller* and *MARIA-n* — it trades Fatal Maid 59 / MARIA-n 63 for 57 / 65 at the price of a cut-off day carrying one NIKKE (*Label*, c582) and no Sin Editor marquee; every line above uses Fatal Maid.)

The settled line — **Golden Coin Rush → Old Tales → Memories Teller → Fatal Maid → MARIA-n** — is picked because:

- *Memories Teller* and *Golden Coin Rush* — the two favorite events — each name a set; among the lines that cut at both, the deficit (25) is the lowest found, tied only with the *Footstep* line (the *Kill the Lord* head line scores 24, but only by forfeiting the *Golden Coin Rush* name);
- the tie with *Footstep* breaks on where the deficit sits: *Footstep* parks 13 of the 25 in *Memories Teller* itself (47) and its cut-off day (2024-12-26) carries no new NIKKE at all (two sub-flavors only), while the settled line keeps *Memories Teller* at 57 (3 below the floor) and puts the bulk (21 of the 25) in *Old Tales* — a non-favorite event whose cut-off day carries five new NIKKEs (Cinderella, Rapunzel: Pure Grace, Leviathan, Scarlet: Black Shadow Longing Flower, Isabel Honeymoon Party) and the fairy-tale story kit;
- every other set's marquee NIKKE is dated on the cut-off day (*Mary Medical Rabbit* and *Soda: Twinkling Bunny* at *Golden Coin Rush*; EVE at *Memories Teller*; *Velvet* at *Fatal Maid*; *Rapunzel: Sanctuary* at *MARIA-n*), so each set's name matches its content;
- none of the cut-offs lands on the 2024-09-19 double-event date (Nonsense Red and Jinx Player start the same day — no single name); its event CGs ride in as *Old Tales* extras;
- the tail collapses to one model (*Scarlet: Goddeath*), the line's shortest possible pending set — the previous line's tail held 19.
